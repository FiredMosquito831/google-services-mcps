# google-services-mcps

The short name of [@firedmosquito831/google-services-mcps](https://www.npmjs.com/package/@firedmosquito831/google-services-mcps). It is the same installer, and it runs that package, so both names always work the same way.

```sh
npx google-services-mcps
```

With no arguments, in a terminal, this opens a menu of every command. Install and uninstall also work with flags:

```sh
npx google-services-mcps install --agent claude --plugin gmail
npx google-services-mcps uninstall --all --yes
```

Every command and option is in the [full documentation](https://github.com/FiredMosquito831/google-services-mcps/blob/main/docs/INSTALL.md#npm-and-npx-commands).
