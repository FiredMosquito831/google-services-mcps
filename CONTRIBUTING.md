# Contributing to google-services-mcps

Thank you for helping. The project is maintained by [@FiredMosquito831](https://github.com/FiredMosquito831).

- **Start with an issue** for a bug or a feature request. Use the issue templates. Remove tokens, client secrets, API keys, account data and private mail or file content before you post.
- **Before a pull request**, run the checks from the [Contributing section of the README](README.md#contributing): `npm run typecheck`, `npm test`, `npm run build` and `node scripts/smoke.mjs`.
- **Keep changes focused.** Say what changed and why, and fill in the pull request template.
- **Security problems** are not for public issues. See [docs/SECURITY.md](docs/SECURITY.md) and the [Security section of the README](README.md#security).
