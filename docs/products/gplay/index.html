Product

Google Play

Google Play developer publishing and reporting, Play Games Services, Android Enterprise and Management, Play Integrity and device APIs.

Install

gplay is one plugin in the google-services-mcps marketplace, and it runs one MCP server with the same name. Install it for Claude Code with the command below. For Codex, OpenCode or Antigravity, change --agent; the product id stays the same.

Install for Claude Code

npx google-services-mcps install --agent claude --plugin gplay

What you can do with it

Each task below is one the server can do, with the tool that does it in brackets. A task marked through api_call is one gateway method of an API the product already carries; the gateway tools reach every method of those APIs.

  • List tracks (androidpub_edits_tracks_list)
  • Read a release (androidpub_edits_tracks_get)
  • Upload a bundle (androidpub_upload_bundle)
  • Check Play Integrity (playintegr_v1_decode_integrity_token)

What it manages

The server carries 12 generated API bindings and 7 gateway APIs. Gateway APIs are reached through api_search, api_describe and api_call, which every product with gateway APIs lists.

Tools

The plugin's server registers 366 tools: 170 reads, 148 writes, 47 destructive actions and 1 dynamic tools. A read never asks. A write is listed only when Allow write tools is on, and asks before it runs. A destructive action asks twice. A dynamic tool decides per call.

Sign-in

gplay belongs to the service-account login group. This group uses a service account key, not a login. Create the key in the Google Cloud console, then run npx google-services-mcps setup-service-account with its path. The suite stores only the path, the account address and the time.

The plugin's scope file lists 9 OAuth scopes for 1 APIs. A login asks only for the scopes of its profile: readonly (the default), readwrite, full, or an exact list.
