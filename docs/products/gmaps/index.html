Product

Maps and Location

Maps Platform and location APIs: Places, Address Validation, Solar, Air Quality, Pollen, Street View Publish and related datasets.

Install

gmaps is one plugin in the google-services-mcps marketplace, and it runs one MCP server with the same name. Install it for Claude Code with the command below. For Codex, OpenCode or Antigravity, change --agent; the product id stays the same.

Install for Claude Code

npx google-services-mcps install --agent claude --plugin gmaps

What you can do with it

Each task below is one the server can do, with the tool that does it in brackets. A task marked through api_call is one gateway method of an API the product already carries; the gateway tools reach every method of those APIs.

  • Search for places (places_places_search_text)
  • Validate an address (addressval_v1_validate_address)
  • Read air quality for a location (airquality_current_conditions_lookup)
  • Publish a Street View image (streetview_photo_create)

Sign-in

gmaps belongs to the apikey login group. This group uses an API key, not a login. Save the key with npx google-services-mcps setup-apikey; the key is read from the environment or standard input and is never a command-line argument.

The plugin's scope file lists 9 OAuth scopes for 1 APIs. A login asks only for the scopes of its profile: readonly (the default), readwrite, full, or an exact list.
