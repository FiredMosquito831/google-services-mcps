Product

Google Drive and Docs

Google Drive files, labels and activity, plus Docs, Sheets, Slides, Forms and Books.

Install

gdrive is one plugin in the google-services-mcps marketplace, and it runs one MCP server with the same name. Install it for Claude Code with the command below. For Codex, OpenCode or Antigravity, change --agent; the product id stays the same.

Install for Claude Code

npx google-services-mcps install --agent claude --plugin gdrive

What you can do with it

Each task below is one the server can do, with the tool that does it in brackets. A task marked through api_call is one gateway method of an API the product already carries; the gateway tools reach every method of those APIs.

  • List files in a folder (drive_files_list)
  • Read a Google Doc (drive_read_text)
  • Append rows to a Sheet (sheets_spreadsheets_values_append)
  • Create a Form (forms_forms_create)
  • Move or label a file (drive_update_file)

What it manages

The server carries 8 generated API bindings and 2 gateway APIs. Gateway APIs are reached through api_search, api_describe and api_call, which every product with gateway APIs lists.

Sign-in

gdrive belongs to the workspace-user login group. Log in once for the group: create a Desktop OAuth client in a Google Cloud project, save its file with npx google-services-mcps setup-client, then run npx google-services-mcps login workspace-user. Products in this group share the one login.

The plugin's scope file lists 26 OAuth scopes for 1 APIs. A login asks only for the scopes of its profile: readonly (the default), readwrite, full, or an exact list.
