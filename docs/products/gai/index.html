Product

AI and ML

Generative and classic AI APIs: Discovery Engine, Vertex AI, Dialogflow, Vision, Speech, Translate, Document AI and agent services.

Install

gai is one plugin in the google-services-mcps marketplace, and it runs one MCP server with the same name. Install it for Claude Code with the command below. For Codex, OpenCode or Antigravity, change --agent; the product id stays the same.

Install for Claude Code

npx google-services-mcps install --agent claude --plugin gai

What you can do with it

Each task below is one the server can do, with the tool that does it in brackets. A task marked through api_call is one gateway method of an API the product already carries; the gateway tools reach every method of those APIs.

  • Run a Vision request (vision_images_annotate)
  • Translate text (through api_call, method translate.projects.translateText)
  • Query Vertex AI (vertex_generate_content)
  • Run Document AI (through api_call, method documentai.projects.locations.processors.process)
