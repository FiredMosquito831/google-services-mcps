Product

Workspace Admin

Google Workspace administration: Cloud Identity, Chrome management and policy, Groups Settings, licensing, reports, alerts, Vault, reseller and Cloud Search admin.

Install

gadmin is one plugin in the google-services-mcps marketplace, and it runs one MCP server with the same name. Install it for Claude Code with the command below. For Codex, OpenCode or Antigravity, change --agent; the product id stays the same.

Install for Claude Code

npx google-services-mcps install --agent claude --plugin gadmin

What you can do with it

Each task below is one the server can do, with the tool that does it in brackets. A task marked through api_call is one gateway method of an API the product already carries; the gateway tools reach every method of those APIs.

  • List users in the directory (admin_users_list)
  • Create a group (admin_group_create)
  • Read an audit report (admin_activities_list)
  • Read the Chrome policy schemas (chromepoli_policy_schemas_list)
  • List Vault matters and holds (vault_matters_list)

Sign-in

gadmin belongs to the workspace-admin login group. This group uses a service account with domain-wide delegation, not a user login. Create the service account and its JSON key, allow its client ID in the Google Admin console under Domain-wide delegation, then run npx google-services-mcps setup-admin.
