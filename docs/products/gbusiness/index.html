Product

Business Profile

Business Profile accounts, locations, verifications, lodging, place actions, notifications and performance.

Install

gbusiness is one plugin in the google-services-mcps marketplace, and it runs one MCP server with the same name. Install it for Claude Code with the command below. For Codex, OpenCode or Antigravity, change --agent; the product id stays the same.

Install for Claude Code

npx google-services-mcps install --agent claude --plugin gbusiness

What you can do with it

Each task below is one the server can do, with the tool that does it in brackets. A task marked through api_call is one gateway method of an API the product already carries; the gateway tools reach every method of those APIs.

  • List accounts and locations (mbaccount_accounts_list)
  • Read a location's attributes (mbinfo_locations_get_attributes)
  • List place action links (mybusiness_links_list)
  • Pull performance metrics (bpperf_loc_get_dai_met_tim_seri)

Sign-in

gbusiness belongs to the business login group. Log in once for the group: create a Desktop OAuth client in a Google Cloud project, save its file with npx google-services-mcps setup-client, then run npx google-services-mcps login business.

The plugin's scope file (scopes.json) lists no OAuth scopes for this product. Its server file (servers.json) declares the scopes its APIs ask for, listed below, because the APIs' Discovery documents list none; the login asks only for those its profile needs.
