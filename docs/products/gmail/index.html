Product

Gmail

Gmail mailboxes, messages, labels and settings, plus Gmail Postmaster Tools.

Install

gmail is one plugin in the google-services-mcps marketplace, and it runs one MCP server with the same name. Install it for Claude Code with the command below. For Codex, OpenCode or Antigravity, change --agent; the product id stays the same.

Install for Claude Code

npx google-services-mcps install --agent claude --plugin gmail

What you can do with it

Each task below is one the server can do, with the tool that does it in brackets. A task marked through api_call is one gateway method of an API the product already carries; the gateway tools reach every method of those APIs.

  • Search a mailbox for a sender, subject or label (gmail_search)
  • Read a thread and summarise it (gmail_get_thread)
  • Apply or remove a label (gmail_label)
  • Draft and send a message (gmail_create_draft)
  • Check Postmaster Tools reputation (gmailpostm_domains_domain_stats_query)

What it manages

The server carries 2 generated API bindings and 2 gateway APIs. Gateway APIs are reached through api_search, api_describe and api_call, which every product with gateway APIs lists.

Tools

The plugin's server registers 114 tools: 51 reads, 37 writes, 25 destructive actions and 1 dynamic tools. A read never asks. A write is listed only when Allow write tools is on, and asks before it runs. A destructive action asks twice. A dynamic tool decides per call.

Sign-in

gmail belongs to the workspace-user login group. Log in once for the group: create a Desktop OAuth client in a Google Cloud project, save its file with npx google-services-mcps setup-client, then run npx google-services-mcps login workspace-user. Products in this group share the one login.

The plugin's scope file lists 18 OAuth scopes for 1 APIs. A login asks only for the scopes of its profile: readonly (the default), readwrite, full, or an exact list.
