Product

Search Console

Search Console sites, sitemaps, search analytics, URL indexing and site verification.

Install

gsc is one plugin in the google-services-mcps marketplace, and it runs one MCP server with the same name. Install it for Claude Code with the command below. For Codex, OpenCode or Antigravity, change --agent; the product id stays the same.

Install for Claude Code

npx google-services-mcps install --agent claude --plugin gsc

What you can do with it

Each task below is one the server can do, with the tool that does it in brackets. A task marked through api_call is one gateway method of an API the product already carries; the gateway tools reach every method of those APIs.

  • List the verified sites on the account (sc_sites_list)
  • Submit or resubmit a sitemap (sc_sitemap_submit)
  • Run a search analytics query by query, page or country (sc_search_analytics_query)
  • Inspect a URL's index status (sc_url_inspect)
  • Request indexing for a URL (indexing_url_notifications_publish)

Sign-in

gsc belongs to the searchconsole login group. Log in once for the group: create a Desktop OAuth client in a Google Cloud project, save its file with npx google-services-mcps setup-client, then run npx google-services-mcps login searchconsole.

The plugin's scope file lists 5 OAuth scopes for 1 APIs. A login asks only for the scopes of its profile: readonly (the default), readwrite, full, or an exact list.
