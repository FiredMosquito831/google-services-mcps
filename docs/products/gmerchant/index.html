Product

Merchant Center

Merchant Center: Merchant API and Comparison Shopping Service, through a service account key.

Install

gmerchant is one plugin in the google-services-mcps marketplace, and it runs one MCP server with the same name. Install it for Claude Code with the command below. For Codex, OpenCode or Antigravity, change --agent; the product id stays the same.

Install for Claude Code

npx google-services-mcps install --agent claude --plugin gmerchant

Sign-in

gmerchant belongs to the service-account login group. This group uses a service account key, not a login. Create the key in the Google Cloud console, then run npx google-services-mcps setup-service-account with its path. The suite stores only the path, the account address and the time.

The plugin's scope file lists 2 OAuth scopes for 1 APIs. A login asks only for the scopes of its profile: readonly (the default), readwrite, full, or an exact list.
