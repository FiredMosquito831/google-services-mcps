Product

Firebase

Firebase management, App Check, App Distribution, Crashlytics, Hosting, Data Connect, Rules, Test Lab, FCM and Identity Toolkit.

Install

gfirebase is one plugin in the google-services-mcps marketplace, and it runs one MCP server with the same name. Install it for Claude Code with the command below. For Codex, OpenCode or Antigravity, change --agent; the product id stays the same.

Install for Claude Code

npx google-services-mcps install --agent claude --plugin gfirebase

What you can do with it

Each task below is one the server can do, with the tool that does it in brackets. A task marked through api_call is one gateway method of an API the product already carries; the gateway tools reach every method of those APIs.

  • List Firebase projects (firebase_projects_list)
  • Deploy Hosting (through api_call, method firebasehosting.sites.versions.create)
  • Read Crashlytics reports (firebasecr_apps_reports_list)
  • Manage App Check (firebaseap_services_list)

Sign-in

gfirebase belongs to the developer login group. Log in once for the group: create a Desktop OAuth client in a Google Cloud project, save its file with npx google-services-mcps setup-client, then run npx google-services-mcps login developer.

The plugin's scope file lists 5 OAuth scopes for 1 APIs. A login asks only for the scopes of its profile: readonly (the default), readwrite, full, or an exact list.
