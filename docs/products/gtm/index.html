Product

Tag Manager

Google Tag Manager accounts, containers, tags, triggers and variables.

Install

gtm is one plugin in the google-services-mcps marketplace, and it runs one MCP server with the same name. Install it for Claude Code with the command below. For Codex, OpenCode or Antigravity, change --agent; the product id stays the same.

Install for Claude Code

npx google-services-mcps install --agent claude --plugin gtm

What it manages

The server carries 1 generated API bindings and 1 gateway APIs. Gateway APIs are reached through api_search, api_describe and api_call, which every product with gateway APIs lists.

Sign-in

gtm belongs to the business login group. Log in once for the group: create a Desktop OAuth client in a Google Cloud project, save its file with npx google-services-mcps setup-client, then run npx google-services-mcps login business.

The plugin's scope file lists 7 OAuth scopes for 1 APIs. A login asks only for the scopes of its profile: readonly (the default), readwrite, full, or an exact list.
