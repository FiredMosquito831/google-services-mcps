Harness

Google MCP servers for Codex

The suite is 23 MCP servers for Google products, one plugin per product, and the same servers run in Codex. This page covers the install command for Codex, where it writes, and what Codex does and does not do about approvals.

Install a product for Codex

Every product uses the same command. Change the product id to install another one, or pass --plugin all to install every product at once.

Install Gmail for Codex

npx google-services-mcps install --agent codex --plugin gmail

The installer copies each product's server files to ~/.google-services-mcps/runtime/<product>/ and writes one entry per server into a block of config.toml that it owns, between marker lines. Text outside the block is never changed.

The default scope is global, which is your account. The installer writes ~/.codex/config.toml for the global scope, and .codex/config.toml in a folder for the project and local scopes. Add --dry-run to see every change without writing one.

Where it writes

The Codex configuration files

global (default)~/.codex/config.toml

Approvals in Codex

Codex has no consent hook in this suite. A client that cannot ask for approval is refused every change, so nothing runs without a confirmation.

Reads never ask. A write is listed only when Allow write tools is on, and a destructive action asks twice in Claude Code. The full consent model is on the architecture page.

What you need

Codex, and Node.js 20 or newer. Codex reads a project config.toml only in a trusted project, so trust the folder or its servers stay off.

The 23 products

Each product is one plugin and one MCP server. The list is generated from the plugin folders at build time; every product page shows the tools that server registers.

    gadmin

    Google Workspace administration: Cloud Identity, Chrome management and policy, Groups Settings, licensing, reports, alerts, Vault, reseller and Cloud Search admin.

    364 tools · cloud login

    83 tools · business login

    26 tools · workspace-user login

  • Business Profile

    gbusiness

    59 tools · business login

  • Google Calendar

    55 tools · workspace-user login

Keeping it current

Run the install again after a new release, so the runtime copy and the config entry are refreshed.
