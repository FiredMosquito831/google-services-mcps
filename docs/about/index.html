About

About this project

google-services-mcps is an independent project by FiredMosquito831. It packages Google's APIs as Model Context Protocol servers, one plugin per product, so an AI agent can work with Google data under controls you set.

Status

Version 2.17.0, in beta. The code is built and tested offline: the unit and build tests pass, a smoke test starts all 23 servers over stdio, and Claude plugin validation passes for the marketplace and the Gmail plugin. Three products have run against live Google accounts: gcloud, gsc and gmail. Nothing else has, and no mail has been sent. The home page and the FAQ say the same thing in their own words.

How it is built

The suite is built from Google's published Discovery documents and the Model Context Protocol specification. A product map in config/products.json is the source of truth: each product has a login group, a server name, a curated module or none, a list of generated APIs and a list of gateway APIs. The build turns that map and the Discovery snapshots into the plugin folders under plugins/, one per product.

The project studied community MCP projects for design ideas only, including googleapis/gcloud-mcp, taylorwilsdon/google_workspace_mcp and mikusnuz/gsc-mcp, and others. It copied no code from them.

What it is not

  • It is not an official Google product. It is not affiliated with, endorsed by or sponsored by Google LLC.
  • It is not a hosted service. The servers run on your machine, as you, and call Google directly.
  • It is not a way around Google's rules. Quotas, billing, approval rules and restricted-scope verification apply to every call.
  • It is not finished. The approval hook and the approval form have not been exercised in a live Claude Code session, and most products have not run against a real account.

This site

The site is generated from the repository by scripts/build_site.py, which reads the plugin manifests and writes the pages, the sitemap and the assets. The product reference on this site is computed at build time: the product count, the tool counts and the scope counts come from the plugin folders, not from a typed list. The site loads no external fonts, scripts, analytics or embeds.
