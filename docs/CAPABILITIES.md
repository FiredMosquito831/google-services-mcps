Toolsets: the plugin option `toolset` (`GSM_TOOLSET`, `gsm install --toolset`) picks which tools a server lists. all is every tool (the default). google is the tools that match Google's official MCP server for the product, or a small set chosen here where Google has no server (gsc, gmeet, gtasks, gapps, gtm, gyoutube, gbusiness). curated is the hand-written tools and the gateway tools. "(all)" means the product has no such toolset yet, so it lists every tool. Each count includes the 9 runtime tools of the tool map (health, sign-in and account tools); a server lists only those of its sign-in kind, and write tools only when writes are allowed. Antigravity is reported to refuse a server with more than 100 tools (not verified); `gsm install --agent agy` warns.

## What the safety classes mean

- **read**: never asks. Lists, gets, searches and reports.
- **write**: creates or changes data. Asks first unless the confirmation option is off.
- **destructive**: deletes, removes, sends, disables or otherwise cannot be undone easily. Asks first, and the confirmation is shown twice (hook prompt and exact preview), unless the option is off.
- **dynamic**: the risk depends on the call. Google Ads mutate is read when validateOnly is set, destructive when any operation removes, and write otherwise.

## Gateway tools (products with gateway APIs)

Products with gateway APIs also expose `api_search`, `api_describe` and `api_call`, which reach those APIs.

- `api_search`: find methods by text in an API the product covers. Read.
- `api_describe`: parameters, request body and scopes of one method. Read.
- `api_call`: call any method of the product, subject to the same safety classes.
